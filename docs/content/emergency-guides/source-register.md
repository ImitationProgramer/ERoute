## 2025판 본문·정오표 대조

검토한 첨부: [260209 PDF](https://www.kdca.go.kr/bbs/kdca/49/305205/download.do), 531 PDF 페이지. 인쇄쪽과 PDF 위치가 다르며 이 문서에서는 인쇄쪽을 먼저 기록한다. PDF 원문/PNG를 저장소 공개 산출물이나 앱 자산으로 옮기지 않았다.

- 일반인 CPR: 인쇄쪽 57(PDF 75, 그림 3-1), 60~70(PDF 78~88), 78(PDF 96). 신고 우선, 비정상 호흡·정상 호흡의 분기, 일반인 맥박 확인 제외, 압박/인공호흡의 조건·이완·중단·인계 범위를 읽었다. 그림 3-1·3-9·3-10도 렌더링 확인. S03의 시작/종료 조건 생략을 해소하지 않고 공개 승인하지 않는다.
- AED: 인쇄쪽 81~84(PDF 99~102), 그림 3-15(PDF 101) 렌더링 확인. 완전자동/반자동, 음성 안내, 접촉 금지, 충격 불필요 분기, 즉시 CPR 재개와 2분 재분석을 대조했다. S04의 ‘5주기’를 가슴압박만 하는 사람에게 일반화하지 않으며 버튼 문구도 일괄 적용하지 않는다.
- 연령: 인쇄쪽 284(PDF 302)를 렌더링 확인. 해당 지침은 성인 분류를 만 8세부터로 정한다. 가입 만 14세와 별개다. 인쇄쪽 68의 보통 체격 기준을 기계적으로 연령에 대입하지 않는다. 원고의 환자 대상 문장 확정은 전문가 검토 PENDING.
- [정오표 1차(2026-02-09)](https://www.kdca.go.kr/bbs/kdca/49/305206/download.do) 1쪽 전체를 렌더링했다. 인쇄쪽 125(PDF 143), 그림 4-1의 충격불필요리듬 상자를 ‘무수축/무맥성전기활동’으로 고친 내용이다. 260209 PDF의 해당 그림과 일치한다. 제4장 병원 내 전문소생술 대상이며, v1에 전문소생술을 추가하지 않는다.
- 외부 출혈·열화상: 제10장 목차(PDF 14)와 실제 본문 인쇄쪽 491~502를 확인했다. 가슴통증·뇌졸중·천식·아나필락시스·경련·쇼크·실신을 다루며 두 후보의 처치 절차가 없다. 최신성 검증을 완료했다고 하지 않는다.
- 2026-09-15 게시물 및 KDCA 정오표 검색에서 확인한 첨부는 1차 정오표다. 다른 정정의 부재를 영구 보장하지 않으며 다음 원고 개정 때 재확인한다.

## 이용조건 정책

- S08 [소방청 저작권 정책](https://www.nfa.go.kr/nfa/operationguide/copyrightolicy/): 개별 표시 확인, 출처 명시, 미표시 자료 사전 협의. 게시일 미표시.
- S09 [공공누리 제1유형](https://www.kogl.or.kr/info/licenseType1.do): 출처표시 조건의 상업적 이용/변경 가능. 앱을 기관 인증/후원으로 표시하지 않음. S03~S06/S12의 확인된 범위는 별도 허락 PENDING으로 되돌리지 않음.
- S10 [공공누리 제4유형](https://www.kogl.or.kr/info/licenseType4.do): 상업적 이용금지·변경금지. 별도 허락 또는 재사용 가능한 대체 자료/검토된 독자 작성 경로가 필요. 단순 의역으로 권리를 해결했다고 하지 않음.
- 별도 허락 수령: **없음**. `permissionGrantedBy`/`permissionGrantedAt`: null. 제1유형 부분 원고는 `NOT_REQUIRED_WITHIN_KOGL1`; 미표시 자료는 PENDING; S07 재사용은 RESTRICTED.
- 의료 검토 수령: **없음**. 모든 원고 `medicalReviewStatus=PENDING`, 검토자/일 null. 출처 확인일은 의료 검토일과 다르다.

## v1.1 재대조 (2026-09-16 UTC)

- S12 공식 페이지의 ‘위치를 잘 모를 때’ 1~3항과 고속도로 예시, ‘응급 환자가 생겼을 때’ 1~4항, 복용약 준비 문단, 하단 **텍스트에 한한 제1유형** 문구를 재확인했다. 도로 이름/방향/숫자는 기존 원문에 이미 있다. 통화 종료/위치 정정 규칙은 해당 범위에 제시되지 않는다. 기사 속 다른 의료 지시는 이번 범위로 가져오지 않았다.
- S01/S02 및 S03~S06은 web 도구에서 방문자 확인/접근 실패가 있었으나 같은 공식 URL을 직접 HTTP로 읽을 수 있었다. S01/S02 이미지의 대체 텍스트를 읽고, S03~S06은 위 등록부의 정확한 JPG를 직접 열어 전체 그림을 재대조했다. S03~S06의 개별 제1유형 표시는 유지된다. S01/S02에 개별 허용 표시를 확보하지 못했으므로 미확정 경계 유지. S02 이미지 3에는 응급처치를 하는 사람 외의 다른 동행인 조건이 실제로 있다.
- S07 공식 게시물의 260209 PDF(531쪽), 1차 정오표·제4유형 표시를 재확인했다. 인쇄쪽 57~84(PDF 75~102), 연령 284(PDF 302), 제10장 491~502(PDF 509~520)를 대조했다. 그림 3-1(PDF 75), 3-15(PDF 101)과 정오표 1쪽은 페이지 이미지로 확인했다. 일반인/의료인 절을 구분했으며 원고에 제4유형 표현·도표를 재가공하지 않았다. 출혈/열화상 절차가 제10장에 없다는 점도 재확인했다. 이 조사 범위에서 후속 정오표를 확보하지 못했으며 부재를 보장하지 않는다.

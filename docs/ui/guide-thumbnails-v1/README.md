# 가이드 썸네일 v1.1

7개 개별 일러스트를 built-in image_gen으로 제작했다. 핵심 물체를 크게 표현한 동일 계열 파스텔·남색 스타일이며 처치 자세·글자·기관 표장·재생 표시를 포함하지 않는다.

- [7개 비교](comparison.png): 제목은 비교 문서에서 별도 조판했으며 앱 이미지에는 포함하지 않는다.
- [생성 프롬프트](generation.json): 도구·원본 생성 위치·주제별 전체 프롬프트.
- [원본/파생 manifest](manifest.json): 실제 크기·바이트·SHA-256·제작 방법·범위. `originals/*.png`는 생성 래스터 원본이며 벡터가 아니다.
- 목록 파생본: `apps/mobile/assets/illustrations/guides/*.webp`, 각각 384×240. 전체 프레임을 LANCZOS 축소 후 WebP quality 88로 저장했다. 합계 56,928 bytes.
- 공식 웹 자료의 그림·영상·사진을 복제하거나 비교표를 잘라서 원본으로 사용하지 않았다. 단순 책 아이콘 색상 변형이 아니다.
- 제작·화면 적용 확인은 의료 검토·공개 본문 승인·독점적 권리 보장이 아니다.
